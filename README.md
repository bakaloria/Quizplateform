# منصة الاختبارات التفاعلية — Interactive Quiz Platform

منصة ويب احترافية باللغة العربية لإنشاء اختبارات إلكترونية وإدارتها وتنفيذها عبر المتصفح.
تعمل بتقنية **Firebase Firestore** (بدون خادم خلفي) وتُشغَّل مباشرة من ملف `index.html` أو عبر أي
استضافة ثابتة.

- **الإدارة:** إنشاء مواد، بنك أسئلة، استيراد دفعات، إنشاء اختبارات بكود دخول، متابعة النتائج وتصدير CSV.
- **الطلاب:** دخول بكود الاختبار، حل مع مؤقّت، وعرض النتيجة مع مراجعة الإجابات.
- **v7:** تحديد عدد الأسئلة حسب النوع أثناء إنشاء الاختبار، ترتيب أسئلة الاختبار باليد من لوحة المدير،
  وكشف الأسئلة المكررة تلقائياً عند الاستيراد والإضافة.

---

## 1) التشغيل السريع

### أ) فتح مباشر
افتح ملف `index.html` في المتصفح. التطبيق مُهيّأ للعمل حتى عبر `file://` (يُحمَّل Firebase من CDN).

### ب) خادم محلي (موصى به)
```bash
cd quiz-platform
python3 -m http.server 8080
# ثم افتح http://127.0.0.1:8080/
```

> ملاحظة: التطبيق يحتاج اتصالاً بالإنترنت لتحميل مكتبات Firebase من `gstatic.com`.

---

## 2) إعداد Firebase

إعدادات Firebase مضمّنة مسبقاً في `js/firebase.js` (المشروع: `tasks-for-quran`).

إذا أردت استخدام مشروعيك الخاص، استبدل كائن الإعداد في `js/firebase.js`:

```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

ثم فعّل **Cloud Firestore** من لوحة Firebase لمشروعك.

### قواعد أمان Firestore
التطبيق لا يستخدم Firebase Auth، لذا يجب أن تسمح قواعد Firestore بالوصول العام ليعمل التطبيق.
من لوحة Firebase → Firestore → **Rules** ضع:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

> ⚠️ **تحذير أمني:** قواعد `if true` تسمح لأي شخص بقراءة/كتابة/حذف البيانات لأصحاب الكود.
> هذه منصة داخلية/تعليمية، ولا تُستخدم لبيانات حسّاسة. لحماية حقيقية أضف Firebase Auth وقيّد
> العمليات على مستخدم موثّق.

## 3) لوحة المدير

- الوجهة: `#/admin`
- **رمز الدخول الافتراضي:** `admin123` (يُنشئه التطبيق تلقائياً ويُخزَّن في وثيقة `settings/admin`).
  غيّره من: **الإعدادات ← كلمة مرور المدير**.
- جلسة الإدارة تُحفظ في `sessionStorage` (`qp_admin=1`) وتُمسح بإغلاق التبويب.

الأقسام:
1. **لوحة المعلومات:** إحصاءات سريعة وحالة النظام.
2. **المواد:** إضافة/تعديل/حذف المواد الدراسية.
3. **بنك الأسئلة:** إضافة/تعديل/حذف أسئلة، بحث وتصفية حسب المادة والنوع، واستيراد دفعات.
4. **الاختبارات:** إنشاء اختبار من بنك الأسئلة، توليد كود دخول، ضبط المدة والترتيب العشوائي ونسبة النجاح.
5. **النتائج:** مشاركون، متوسط، توزيع نسب، وتصدير CSV.
6. **الإعدادات:** تغيير رمز المدير، تصدير/استيراد نسخة احتياطية JSON.

### 3.1) تحديد عدد الأسئلة حسب النوع (v7)

داخل نافذة **إنشاء/تعديل اختبار**، قسم «تحديد عدد الأسئلة حسب النوع» يعرض كل نوع سؤال مع عدد المتاح
لديه حسب الفلاتر المختارة (مادة/وحدات/دروس). اكتب العدد المطلوب من كل نوع ثم اضغط **«جلب حسب الأنواع»**
ويُضاف العدد تلقائياً — أو اضغط **«توزيع متوازن»** لتوزيع العدد الكلي تلقائياً بنسبة توافره في البنك.

### 3.2) ترتيب أسئلة الاختبار (v7)

قسم «الأسئلة المختارة» أسفل النافذة يعرض كل الأسئلة المضافـة إلى الاختبار، مع أزرار
«أعلى/أسفل/إزالة». **الطلاب يرون الأسئلة بالترتيب الذي اعتمدته أنت في لوحة التحكم**
إلا إذا فُعّل خيار «ترتيب عشوائي» (الافتراضي: معطّل).

### 3.3) كشف الأسئلة المكررة (v7)

- **استيراد دفعات:** تُعرض شارة «مكرر» في المعاينة لكل سؤال مطابق (نص مُوحّد يتجاهل التشكيل والهمزات
  وتاء المربوطة واختلاف الألف/الياء) لسؤال موجود في المادة نفسها، ويُتجاهل المكرر تلقائياً عند الاستيراد.
- **إضافة سؤال يدوياً:** يُطلب تأكيد قبل إضافة سؤال مطابق لسؤال موجود في المادة.

## 4) تجربة الطالب

- الوجهة: `#/join` (أو `#/join/CODE`)
- الطالب يُدخل كود الاختبار ثم اسمه ويبدأ.
- أثناء الحل: مؤقّت، شبكة تنقّل بين الأسئلة، تعليم للمراجعة، حفظ تلقائي للمحاولة الحالية.
- الأسئلة تظهر **بالترتيب الذي رتّبه المدير** ما لم يفعّل خيار الترتيب العشوائي.
- عند التسليم: تُحتسب النتيجة تلقائياً وتُحفظ في `submissions`.

## 5) أنواع الأسئلة المدعومة

| النوع | `type` | التخزين والتصحيح |
|-------|--------|------------------|
| اختيار من متعدد | `mcq` | خيار واحد صحيح، تطابق مباشر |
| متعدد الإجابات | `multi` | عدة خيارات صحيحة، تطابق مجموعة كاملة |
| صح أو خطأ | `true_false` | `صح` / `خطأ` |
| أكمل الفراغ | `fill_blank` | نص، تُقبل البدائل المفصولة بـ `\|` |
| إجابة قصيرة | `short_answer` | نص، تُقبل البدائل المفصولة بـ `\|` |
| مقالي | `essay` | غير مُرقمن تلقائياً (يُصحَّح يدوياً) |

> التصحيح يتجاهل التشكيل والهمزات وتاء المربوطة ونوع الألف/الياء، ويقبل بدائل مثل
> `نيوتن|إسحاق نيوتن`. يمكنك تفعيل **العلامة السالبة** لكل سؤال.

## 6) استيراد الأسئلة دفعة واحدة

من **بنك الأسئلة ← استيراد دفعات** يمكنك لصق النص أو رفع ملف بثلاث صيغ:

### JSON
مصفوفة أسئلة، أو ملف الكتاب بالشكل:
```json
{
  "units": [
    { "unit_title": "الوحدة الأولى", "lessons": [
      { "lesson_title": "الدرس", "questions": [
        { "type": "mcq", "question": "نص السؤال؟", "options": ["أ","ب","ج","د"], "answer": "ب" }
      ]}
    ]}
  ]
}
```

### CSV
الأعمدة: `type,text,option1,option2,option3,option4,answer,points,difficulty`
```csv
type,text,option1,option2,option3,option4,answer,points,difficulty
mcq,"عاصمة سوريا؟",دمشق,حلب,حمص,حماة,دمشق,1,سهل
fill_blank,"اكتشف .......... الجاذبية",,,,,نيوتن|إسحاق نيوتن,2,متوسط
true_false,"الأرض كروية",,,,,صح,1,سهل
```

### قالب نصي
كل سؤال في مقطع منفصل بسطر فارغ. الوسم في البداية اختياري، الخيارات تبدأ بـ `-` والصائب بـ `*`
أو `(صح)`، والإجابة بسطر `الإجابة:`:
```
[اختيار] ما هي عاصمة سورية؟
- حلب
- دمشق (صح)
- حمص

[صح/خطأ] الشمس تشرق من الغرب.
الإجابة: خطأ

[أكمل الفراغ] عُقد مؤتمر ......... عام 1878م.
الإجابة: برلين
```
(زر **إدراج مثال** يضع قالباً جاهزاً في حقل الاستيراد.)

## 7) نموذج البيانات (Collections)

| Collection | الوصف |
|------------|-------|
| `subjects` | المواد الدراسية |
| `questions` | بنك الأسئلة |
| `exams` | الاختبارات (تحتوي نسخة الأسئلة + الإعدادات) |
| `examCodes` | كود الدخول → معرّف الاختبار (وثيقة لكل كود) |
| `submissions` | مشاركات الطلاب ودرجاتهم |
| `settings` | إعدادات عامة + `settings/admin` (رمز المدير) |

## 8) بنية المشروع

```
quiz-platform/
├── index.html          # الهيكل + تحميل السكربتات
├── css/styles.css      # نظام التصميم (RTL، داكن/فاتح، متجاوب)
└── js/
    ├── firebase.js     # تهيئة Firebase + QP.db
    ├── utils.js        # أدوات مشتركة (QP.utils)
    ├── importer.js     # محرك استيراد الأسئلة v5.1 (QP.importer)
    ├── store.js        # كل عمليات Firestore (QP.store)
    ├── admin.js        # لوحة المدير v6 (QP.admin) — أنواع حسب العدد + ترتيب + تكرار
    ├── student.js      # تجربة الطالب (QP.student)
    ├── teacher.js      # لوحة المعلم (QP.teacher)
    ├── groups.js       # إدارة المجموعات (QP.groups)
    ├── analytics.js    # تحليلات النتائج
    ├── certificate.js  # شهادات النجاح
    ├── crypto.js       # تشفير/فك بيانات
    ├── pwa.js + sw.js  # تطبيق تقدمي PWA يعمل دون إنترنت بعد أول زيارة
    └── app*.js         # التوجيه والصفحة الرئيسية والثيم
```

## 9) ملاحظات تقنية

- يُحمَّل Firebase عبر `compat` SDK بصيغة سكربتات كلاسيكية (لا وحدات ES modules) ليعمل التطبيق من `file://`.
- ترتيب تحميل السكربتات مهم: `firebase → utils → importer → store → admin → student → app`.
- الواجهة كلها RTL وتعمل على الجوال والحاسوب، وتدعم الوضع الداكن/الفاتح (يُحفظ في `localStorage`).
